## Écarts et remarques

- Les systèmes de démonstration produisent des événements factices. Ils servent uniquement à tester le noyau.
- Les commandes de l'IA ne sont pas journalisées : elles se recalculent à l'identique quand on rejoue. C'est vérifié par le test de rejeu, avec une commande extérieure.
- La compression est faite hors du moteur (gzip), ce qui évite toute dépendance dans le moteur.
- Le titre du site est neutre (« nom de travail ») tant que le nom du jeu n'est pas choisi.
