# Rapports

Rapports produits par les simulations et les outils de diagnostic, à partir de la phase 1.

Nom des fichiers : `AAAA-MM-JJ-<phase>-<sujet>.md` (ex. : `2027-01-15-p3-equilibre-10-saisons.md`).

Chaque rapport indique :
- la version du code (commit) et les graines utilisées, pour pouvoir le reproduire ;
- les indicateurs mesurés, comparés aux fourchettes cibles ;
- ce qui est conforme, ce qui ne l'est pas, et les corrections proposées ;
- si besoin, un extrait de chronique pour la lecture humaine.
