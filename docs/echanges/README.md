# Échanges

Propositions, analyses et messages destinés à être relus par l'équipe, notamment par ChatGPT.

Nom des fichiers : `AAAA-MM-JJ-<auteur>-<sujet>.md`, où l'auteur est `claude`, `chatgpt` ou `porteur`.

Règles :
- Un document = un sujet. Il doit se lire seul, sans avoir besoin du reste de la conversation.
- Une réponse à un document le cite et porte le même sujet (ex. : `2026-11-25-chatgpt-reponse-rapport-phase-0.md`).
- Ce qui est décidé à la suite d'un échange est reporté dans `docs/decisions.md`. Le document d'échange garde la discussion, le journal garde la décision.
- Le code proposé ici n'est qu'une proposition. Seul Claude Code l'intègre dans `src/` (D-023).
